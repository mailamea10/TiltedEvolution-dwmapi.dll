TiltedEvolution - RaceMenu + Parkour Server (protocol v1.8.5)
============================================================

This archive contains the matching Windows server executable and server DLL.
Use it with the companion RaceMenu + Parkour client package; older servers do
not relay the RaceMenu appearance message used by this build.

Extract the archive to a dedicated server folder and run SkyrimTogetherServer.exe.
Keep STServer.dll beside the executable. Configure Windows Firewall and any
router rules for the server's configured UDP port before inviting players.

This is a test/pre-release build intended for the matching client build.
