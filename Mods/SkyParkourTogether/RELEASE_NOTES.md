**SkyParkour Together (Parkour Animations Sync) 1.0.0** shares SkyParkour's animations between Skyrim Together Reborn 1.8.5 players: vaults, climbs, ledge grabs, steps, slides and landing rolls play on your character for everyone, with the same height and variant you got.

One FOMOD for Skyrim **1.5.97**, **1.6.1170 / 1.6.1179** and **1.7.104**. The installer asks for your game version.

**Contents**
- `SKSE/Plugins/SkyParkourTogether.dll`: one SKSE plugin for every runtime (it uses no game addresses).
- `SkyrimTogetherRuntime/SkyrimTogether.exe` for your game version: Skyrim Together Reborn 1.8.5 plus the STR Mod Sync add-on that carries the animations. The 1.5.97 option adds the 1.5.97 launcher files Skyrim Together needs on that version.

**Requirements (every player):** Skyrim Together Reborn 1.8.5, SkyParkour (by Tsptds, not included), SKSE and Address Library for your game version. Works with any regular 1.8.5 server.

Install after Skyrim Together Reborn so its `SkyrimTogether.exe` wins the conflict. See the README in the archive for checks and troubleshooting.

SkyParkour Together is an unofficial compatibility add-on, not affiliated with SkyParkour's author. GPLv3; source in `Mods/SkyParkourTogether` on this branch.
