AllTogether SKSE bundle: what it is built from
==============================================

Launchers and servers: the Together Launcher's targets.txt (pinned in addons.lock), one launcher per Skyrim
Together release and Skyrim runtime, each built from that release's own source with the Plugin API host patch
(Mods/TogetherLauncher/Host) and the four add-ons:

  STR 1.8.3 (official, Nexus)      1.7.104 4917189f, 1.6.1170 db8af2cf          version v1.8.3
  STR 1.8.4 (absol89)              1.7.104 951c3641, 1.6.1170 e8b452d2          version v1.8.4
  STR 1.8.5 (absol89)              1.7.104 0f1876e6, 1.6.1170 043dad02,
                                   1.5.97 e6a097e1 (legacy port, KiLoader)     version v1.8.5
  STR 1.8.7-4 (absol89 playtest)   1.7.104 and 1.6.1170 4b2cd432,
                                   1.5.97 ffece63f (legacy port onto 1.8.7-4)  version v1.8.7-4-g4b2cd432

Each launcher reports exactly the version its release's servers accept. One AllTogether server per release is
built from the same source: the stock server plus Plugin API versions 1 and 2, which relay add-on messages to the
players in range and store nothing.

Add-ons (launcher side, pinned in addons.lock): Ragdoll/Physics Together, SkyParkour Together, RaceMenu Together
and LipSync Together, all sending through the Plugin API rather than the script animation relay.

SKSE plugins: unchanged from each add-on's release (Ragdoll Together 1.0.0, SkyParkour Together 1.0.1, RaceMenu
Together 1.0.0, LipSync Together 0.8.0). Each is one DLL for every runtime.

Not included: absol89's STCampfireSync, a separate mod.
