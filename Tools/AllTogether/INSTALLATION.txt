AllTogether SKSE (Skyrim Together Add-ons Bundle 1)
==================================================

Install this FOMOD with Mod Organizer 2 or Vortex. Select the add-ons you want,
then choose the Skyrim Together version and Skyrim runtime that match your game
and the server you join. Every player must use the same Skyrim Together version.

Supported combinations
----------------------
- STR 1.8.7: Skyrim 1.7.104 or 1.6.1170 / 1.6.1179.
- STR 1.8.6: Skyrim 1.7.104 or 1.6.1170 / 1.6.1179.
- STR 1.8.5: Skyrim 1.7.104, 1.6.1170 / 1.6.1179, or 1.5.97.
- STR 1.8.3: Skyrim 1.7.104 or 1.6.1170 / 1.6.1179.

STR 1.8.7 launchers in this bundle include all four add-on integrations. The
1.8.7 launcher also includes the nametag and player UI features from absol89's
PR #16, including its name privacy fixes. Configure those features in Skyrim
Together's player UI settings; a separate installer file would duplicate the
same launcher code. The older STR versions use the latest matching launchers
from each add-on release.
Skyrim 1.5.97 is supported only with STR 1.8.5. Do not select 1.5.97 with
another STR version; there is no compatible launcher in those packages.

Requirements
------------
- Skyrim Special Edition and SKSE for the selected Skyrim runtime.
- Address Library for SKSE Plugins on Skyrim 1.6.x and 1.7.x.
- Skyrim Together Reborn installed as a mod, matching the selected STR version.
- Windows 8 or newer.

Mod Organizer 2
---------------
MO2 starts SkyrimTogether.exe from the real folder on disk, so file priority
does not replace the launcher. After installing this FOMOD:

1. Right-click AllTogether SKSE > Open in Explorer.
2. Copy the installed SkyrimTogetherReborn folder into your Skyrim Together
   Reborn mod's SkyrimTogetherReborn folder, replacing SkyrimTogether.exe.
   Back up the original first. For Skyrim 1.5.97, copy all four files in that
   folder, including EarlyLoad.dll, TPProcess.exe and the version map.
3. Keep AllTogether SKSE enabled for the selected SKSE add-on plugins.
4. Start using your usual MO2 executable entry for Skyrim Together Reborn.
   Do not start the launcher from the AllTogether SKSE mod folder; it needs the
   rest of Skyrim Together's files beside it.

Vortex
------
Install and deploy the FOMOD. Set AllTogether SKSE to load after Skyrim
Together Reborn so its launcher wins the file conflict, then start the game
through SkyrimTogetherReborn/SkyrimTogether.exe as usual.

All selected add-ons install their SKSE plugin under SKSE/Plugins. You may
select one or several. Each add-on works independently; a feature requires its
own plugin to be installed. Everyone in the session should install the same
add-ons and compatible versions. No server-side mod is required.

Uninstall
---------
For MO2, restore the backed-up launcher files in the Skyrim Together Reborn
mod, then remove AllTogether SKSE. For Vortex, remove the mod and redeploy.
